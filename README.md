# AI训练师刷题（三级）理论

《人工智能训练师（三级）理论知识复习题》移动端刷题网站。

## 题库内容

- **判断题** 300 题
- **单选题** 300 题
- **多选题** 300 题
- 合计 **900 题**（题目与参考答案均来自原 PDF，解析为逐题编写）

## 功能

- 三种题型分类刷题，支持「全部 / 判断 / 单选 / 多选」切换
- 三种模式：**顺序刷题**（自动续刷上次进度，全部答完可从头再来一轮）、**随机刷题**、**错题重练**（答对自动移出错题本）
- **滑动刷题**：手机上手指上滑下一题、下滑上一题（电脑端可用 ↑ ↓ 方向键）
- 作答即判分，显示正确答案与正确选项内容
- **每题解析**：答错自动展开解析，答对可点击「查看解析」按钮展开，随时可看
- **记忆系统**：每题累计记录答对/答错次数（题卡显示"已答 N 次 · 对 X 错 Y"）；已答过的题可点「重新作答」反复刷、次数持续累计
- **错题强化**：错题本按答错次数排序并标记「薄弱」题（答错 ≥2 次），可反复重练
- **统计与重置**：统计页显示累计作答遍数；「重置全部答题记录」可清空从头全新刷
- 答题历史、错题与次数保存在浏览器本地（localStorage），换设备不共享
- 移动端优先设计，支持暗色模式，可添加到手机主屏幕

## 本地使用

直接用浏览器打开 `index.html` 即可（数据内置于 `questions.js`，无需服务器）。

## 部署到 GitHub Pages

1. 将本目录内容推送到 GitHub 仓库
2. 仓库 Settings → Pages → 选择分支部署
3. 访问 `https://<用户名>.github.io/<仓库名>/`
