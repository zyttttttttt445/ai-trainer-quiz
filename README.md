# AI训练师刷题（三级）理论

《人工智能训练师（三级）理论知识复习题》移动端刷题网站。

## 题库内容

- **判断题** 300 题
- **单选题** 300 题
- **多选题** 300 题
- 合计 **900 题**（题目与参考答案均来自原 PDF）

## 功能

- 三种题型分类刷题，支持「全部 / 判断 / 单选 / 多选」切换
- 三种模式：**顺序刷题**（自动续刷上次进度）、**随机刷题**、**错题重练**（答对自动移出错题本）
- 作答即判分，显示正确答案与正确选项内容
- 自动记录答题历史与错题（保存在浏览器本地 localStorage）
- 统计页：总题数、已作答、答对、错题、分题型正确率与环形进度图
- 移动端优先设计，支持暗色模式，可添加到手机主屏幕

## 本地使用

直接用浏览器打开 `index.html` 即可（数据内置于 `questions.js`，无需服务器）。

## 部署到 GitHub Pages

1. 将本目录内容推送到 GitHub 仓库
2. 仓库 Settings → Pages → 选择分支部署
3. 访问 `https://<用户名>.github.io/<仓库名>/`
